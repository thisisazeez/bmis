# Week 14 Assignment: Solution (Calculator)

## BMIS 263 -- Introduction to Programming

---

The complete calculator solution is provided as three working files in the `examples/project-starter/` directory:

- `calculator.html` -- the HTML structure
- `calculator.css` -- the styles
- `calculator.js` -- the logic

These files are also embedded in the Week 14 lecture notes with full line-by-line explanations.

---

## Grading Guide

### HTML (10 marks)

| Check | Marks |
|---|---|
| Valid HTML5 structure (doctype, html, head, body) | 2 |
| External CSS linked | 2 |
| External JS linked | 2 |
| At least 10 interactive elements (buttons) | 2 |
| Clean, indented code | 2 |

### CSS (10 marks)

| Check | Marks |
|---|---|
| External file, not inline styles | 2 |
| Calculator has a styled, non-default appearance | 3 |
| Button hover effects | 2 |
| Layout uses Grid or Flexbox (not just browser defaults) | 3 |

### JavaScript: Functions (10 marks)

| Check | Marks |
|---|---|
| At least 3 named functions | 3 |
| Functions have single, clear responsibilities | 3 |
| Functions use parameters and/or return values where appropriate | 2 |
| No repeated code that should be in a function | 2 |

### JavaScript: Events (10 marks)

| Check | Marks |
|---|---|
| addEventListener used (not onclick attributes) | 4 |
| Correct event types (click for buttons) | 3 |
| Event handlers respond correctly | 3 |

### JavaScript: DOM Manipulation (10 marks)

| Check | Marks |
|---|---|
| Display updates when buttons are clicked | 4 |
| Uses getElementById or querySelector | 3 |
| Uses textContent (not innerHTML) for text updates | 3 |

### JavaScript: Conditionals and Loops (5 marks)

| Check | Marks |
|---|---|
| At least 1 conditional (if/else) in the logic | 3 |
| At least 1 loop (for attaching event listeners or processing) | 2 |

### Program Works Correctly (15 marks)

| Check | Marks |
|---|---|
| Addition works | 2 |
| Subtraction works | 2 |
| Multiplication works | 2 |
| Division works | 2 |
| Division by zero handled | 2 |
| Clear button works | 2 |
| No console errors during normal use | 3 |

### Code Quality (10 marks)

| Check | Marks |
|---|---|
| At least 8 comments | 3 |
| Descriptive variable names | 3 |
| Consistent formatting and indentation | 2 |
| No unused variables or dead code | 2 |
