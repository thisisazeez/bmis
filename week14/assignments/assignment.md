# Week 14 Assignment: Project Development

## BMIS 263 -- Introduction to Programming

---

## Task

Build a complete, interactive web application using HTML, CSS, and JavaScript. You may choose one of the following projects:

1. **Calculator** (recommended -- fully guided in the lecture)
2. Quiz App
3. Student Result Checker

---

## Requirements (All Projects)

### HTML
- Valid HTML5 document structure
- Semantic elements where appropriate
- At least 10 interactive elements (buttons, inputs, etc.)

### CSS
- External stylesheet (linked via `<link>`)
- Styled layout (not default browser appearance)
- At least 3 different CSS properties used (colour, spacing, borders, etc.)
- Responsive: no horizontal scrollbar on a standard screen

### JavaScript
- External JavaScript file (linked via `<script src="...">`)
- At least 3 functions
- At least 1 event listener using `addEventListener()`
- DOM manipulation (changing content on the page)
- At least 1 conditional statement
- At least 1 loop (in event handler setup, display logic, or data processing)

### Code Quality
- At least 8 comments explaining key parts of your code
- Meaningful variable and function names
- No unused code or console errors

---

## Project 1: Calculator (Recommended)

Follow the lecture guide to build a calculator with:
- Number buttons (0-9) and decimal point
- Operator buttons (+, -, x, /)
- Equals button
- Clear and delete buttons
- A display that updates as the user interacts

See the lecture notes for the complete step-by-step guide.

---

## Project 2: Quiz App

Build a quiz application that:
- Displays one question at a time (at least 5 questions)
- Shows multiple-choice options (at least 3 per question)
- Highlights correct/incorrect answers when the user selects one
- Tracks and displays the score
- Shows final results at the end

---

## Project 3: Student Result Checker

Build an application that:
- Has a form where the user enters a student name and scores for at least 3 subjects
- Calculates the total and average
- Determines the grade (A/B/C/F)
- Determines pass/fail status
- Displays all results on the page in a formatted way
