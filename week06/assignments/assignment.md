# Week 6 Assignment: Introduction to JavaScript

## BMIS 263 -- Introduction to Programming

---

## Part A: Written (Theory -- 30%)

Answer the following in your own words:

1. **What is syntax in programming?** Give an example of a syntax rule in JavaScript. (5 marks)

2. **What is the difference between `alert()` and `console.log()`?** When would you use each one? (5 marks)

---

## Part B: Practical (70%)

### Task 1: Alert Message

Create a file called `hello.html` that:

1. Displays an `alert()` box with the message: "Welcome to Introduction to Programming!"
2. After the alert is dismissed, the page shows a heading (`<h1>`) that says "BMIS 263"

### Task 2: Console Output

In the same file (or a separate file called `console-demo.html`):

1. Use `console.log()` to print your full name
2. Use `console.log()` to print your age as a number (not in quotes)
3. Use `console.log()` to print the sentence: "I am studying [your course name]"
4. Include at least one comment in your JavaScript code explaining what you are doing

### Task 3: Document Write

Create a file called `write-demo.html` that uses `document.write()` to create:

1. A heading with your name
2. A paragraph describing why you are taking this course

---

## Requirements

- All files must be valid HTML5 documents
- JavaScript must be placed inside `<script>` tags at the bottom of the `<body>`
- At least 2 JavaScript comments across all files
