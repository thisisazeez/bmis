# Week 10 Assignment: Loops

## BMIS 263 -- Introduction to Programming

---

## Task

Create a file called `loops.html` containing the following programs.

---

## Program 1: Print Numbers 1 to 10

Use a `for` loop to print the numbers 1 through 10 to the console. Each number should appear on its own line.

---

## Program 2: Multiplication Table

1. Use `prompt()` to ask the user for a number
2. Use a `for` loop to print that number's multiplication table from 1 to 12
3. Display the output in the console in the format: `5 x 1 = 5`, `5 x 2 = 10`, etc.

---

## Program 3: Sum Calculator

1. Use `prompt()` to ask the user for a number N
2. Use a loop to calculate the sum of all numbers from 1 to N
3. Display the result using `alert()`

---

## Program 4: Even and Odd Counter

1. Use a `for` loop to go through numbers 1 to 20
2. For each number, determine if it is even or odd
3. Count how many are even and how many are odd
4. After the loop, display: "Even: [count], Odd: [count]"

---

## Bonus Challenge (Optional)

Use a `while` loop to repeatedly ask the user for a number. Keep a running total. Stop when the user types "done" (or clicks Cancel). Display the total.

---

## Requirements

- Use a `for` loop in at least two programs
- Use a `while` or `do...while` loop in at least one program (or the bonus)
- Use `parseInt()` or `parseFloat()` for number conversion
- Include at least 4 comments across all programs
- No infinite loops
