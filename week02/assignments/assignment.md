# Week 2 Assignment: HTML Basics

## BMIS 263 -- Introduction to Programming

---

## Task

Create **two** HTML pages from scratch. Both must be valid HTML5 documents with the correct structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).

---

## Page 1: Personal Introduction Page

Create a file called `introduction.html` that displays:

1. Your **full name** as the main heading (`<h1>`)
2. Your **course name** as a subheading (`<h2>`)
3. A short paragraph about yourself (at least 3 sentences)
4. An **unordered list** of 3 hobbies or interests
5. A **horizontal rule** (`<hr>`) separating sections

---

## Page 2: Profile Page

Create a file called `profile.html` that includes:

1. A heading with your name
2. An **image** (this can be any image -- download one and place it in the same folder, or use a URL). The image must have a meaningful `alt` attribute.
3. A paragraph describing the image or yourself
4. A **link** to any website you choose (e.g., your university, a favourite website). The link must open in a new tab using `target="_blank"`.
5. An **ordered list** of your top 3 favourite courses (or subjects, or books)

---

## Requirements

- Each file must begin with `<!DOCTYPE html>` and include `<html>`, `<head>` (with `<title>`), and `<body>`.
- Use **semantic, properly nested** tags. No unclosed tags, no mismatched nesting.
- Include at least **one comment** in each file explaining what a section of your page does.
- Both files must render correctly in Google Chrome or Microsoft Edge with no errors.

---

## Grading Rubric

| Criteria | Marks | Description |
|---|---|---|
| Valid HTML5 structure (both pages) | 10 | Correct doctype, html, head, title, body |
| Required elements on introduction page | 15 | h1, h2, paragraph, unordered list, hr |
| Required elements on profile page | 15 | Heading, image with alt, paragraph, link with target, ordered list |
| Proper tag nesting and closure | 10 | No orphaned or mismatched tags |
| Comments included | 5 | At least one comment per page |
| Code readability (indentation, spacing) | 5 | Clean, consistently indented code |
| **Total** | **60** | |

Submit both `.html` files by the start of Week 3's class.
