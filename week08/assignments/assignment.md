# Week 8 Assignment: Input and Output

## BMIS 263 -- Introduction to Programming

---

## Task

Create a file called `io-program.html` that collects input from the user, processes it, and displays output.

---

## Requirements

### Program 1: Personal Greeting (in the same file)

1. Use `prompt()` to ask for the user's first name
2. Use `prompt()` to ask for the user's last name
3. Use `prompt()` to ask for the user's favourite colour
4. Display an `alert()` that says: "Hello, [first] [last]! Your favourite colour is [colour]."
5. Use a **template literal** for the alert message

### Program 2: Simple Calculator (in the same file or a second file)

1. Use `prompt()` to ask the user for two numbers
2. Convert both inputs to numbers using `parseFloat()`
3. Calculate and display (using `alert()` or `console.log()`) the:
   - Sum
   - Difference
   - Product
   - Quotient (division)
4. Format the output clearly (e.g., "10 + 5 = 15")

### Program 3: Age Calculator (in the same file or a third file)

1. Use `prompt()` to ask the user for their birth year
2. Convert the input to a number
3. Calculate the user's approximate age (current year minus birth year)
4. Display the result using `alert()` with a template literal
