# Week 11 Assignment: Functions

## BMIS 263 -- Introduction to Programming

---

## Task

Create a file called `functions.html` containing the following programs.

---

## Program 1: Display Name Function

Write a function called `displayName` that:

1. Takes a parameter called `name`
2. Prints "Hello, my name is [name]." to the console
3. Call it three times with three different names

---

## Program 2: Greet Function

Write a function called `greet` that:

1. Takes two parameters: `name` and `timeOfDay`
2. Returns a greeting string like "Good morning, Adamu!"
3. Store the returned value in a variable and display it using `alert()`
4. Call it at least twice with different arguments

---

## Program 3: Calculator Functions

Write four functions:

1. `add(a, b)` -- returns `a + b`
2. `subtract(a, b)` -- returns `a - b`
3. `multiply(a, b)` -- returns `a * b`
4. `divide(a, b)` -- returns `a / b`

Then write a main section that:

1. Uses `prompt()` to get two numbers from the user
2. Calls all four functions with those numbers
3. Displays all four results using `console.log()`

---

## Program 4: Grade Calculator Function

Write a function called `getGrade` that:

1. Takes a `score` parameter (a number)
2. Returns the grade as a string ("A", "B", "C", or "F") based on the scoring system from Week 9
3. Call the function with at least 4 different scores and display the results

---

## Requirements

- All functions must use the `function` keyword
- At least two functions must use `return`
- At least one function must take two or more parameters
- Include at least 4 comments explaining what your functions do
