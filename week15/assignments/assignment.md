# Week 15 Assignment: Final Project Presentation & Technical Documentation

## BMIS 263 -- Introduction to Programming

---

## Task

1. Present your final web application project to the class.
2. Submit a completed **Project Technical Documentation** document along with your project source files (`index.html`, `styles.css`, `script.js`).

---

## Requirements

### Part 1: Final Oral Presentation (5 Minutes)
- Demonstrate live app functionality
- Show code structure and highlight at least one key function
- Explain one challenge solved during development
- Answer Q&A

### Part 2: Project Documentation File (`DOCUMENTATION.md`)
Using the template provided in `examples/documentation-template.md`, submit a markdown or PDF document covering:
1. **App Overview & Purpose**: What the application does.
2. **User Interface Design**: Description of HTML layout and CSS styling choices.
3. **Core Functions & Logic**: Description of state variables, functions, and event listeners.
4. **Testing Matrix**: Table showing test inputs, expected results, and actual outcomes.
