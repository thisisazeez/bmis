## Overview

Welcome to the final week of BMIS 263! Over 14 weeks, you transformed from absolute beginners to web developers capable of building interactive, styled web applications.

This week is dedicated to **presenting your final project**, **reviewing key concepts**, and reflecting on your journey across HTML, CSS, and JavaScript.

---

## 1. Final Project Presentation Guidelines

Each student (or team) will give a 5-minute presentation demonstrating their application. Your presentation should cover four main areas:

### 1. Project Overview & Demonstration (2 minutes)
- What does your application do?
- Who is it built for?
- Live demonstration of all core features (normal operation, edge cases, error handling).

### 2. Technical Architecture (1.5 minutes)
- How is your HTML structured?
- How did you handle CSS layout and styling?
- What state variables, functions, and event handlers power your JavaScript?

### 3. Challenges & Solutions (1 minute)
- What bug or obstacle was the hardest to fix?
- How did you debug it? (Console logs, syntax checks, step-by-step logic tracing).

### 4. Code & Q&A (30 seconds)
- Briefly show your clean, commented code.
- Answer one question from the instructor or class.

## 3. Core Concepts Summary Matrix

| Concept | JavaScript Syntax / Tool | Practical Purpose |
|---|---|---|
| Variables | `const x = 5; let y = "hi";` | Memory storage for numbers, text, booleans |
| Data Types | `typeof`, `parseInt()`, `parseFloat()` | Ensuring values are processed correctly |
| Conditionals | `if`, `else if`, `else`, `===`, `&&`, `\|\|` | Making decisions based on state |
| Loops | `for (let i = 0);`, `while ()` | Automating repetitive actions |
| Functions | `function name(param) { return val; }` | Packaging reusable, named logic blocks |
| DOM Selection | `document.getElementById()`, `querySelector()` | Finding HTML elements on the page |
| DOM Mutation | `element.textContent`, `classList.add()` | Updating UI text and styling dynamically |
| Event Listening | `element.addEventListener('click', fn)` | Responding to user interactions without alerts |
| Form Handling | `event.preventDefault()`, `input.value` | Reading user input without page reload |
