# Week 4 Assignment: Introduction to CSS

## BMIS 263 -- Introduction to Programming

---

## Task

Take the profile page you built in Week 2 (or create a new one) and apply CSS styling to transform it from a plain HTML page into a visually styled page.

Create two files:

1. `styled-profile.html` -- your HTML page
2. `styles.css` -- an external CSS file linked to the HTML page

---

## Requirements

### HTML File (`styled-profile.html`)

- Must be a valid HTML5 document
- Must link to `styles.css` using a `<link>` tag in the `<head>`
- Must contain at least: one heading, two paragraphs, one image, one list, and one link
- At least two elements must use a `class` attribute
- At least one element must use an `id` attribute

### CSS File (`styles.css`)

Your stylesheet must demonstrate all of the following:

| Requirement | Details |
|---|---|
| Change the page background colour | Apply a background colour to the `body` |
| Style headings | Change the colour, size, and font-family of at least one heading |
| Style paragraphs | Change the font-size, colour, and line-height of paragraphs |
| Use a class selector | At least one `.classname` rule |
| Use an ID selector | At least one `#idname` rule |
| Style the image | Add a border or border-radius to the image |
| Style the link | Change the link colour (and optionally remove the underline) |
| Add spacing | Use at least one instance of `margin` or `padding` |
| Include at least 2 CSS comments | Explain what your rules do |

---

| Criteria | Marks | Description |

| Paragraphs styled | 5 | Font-size, colour, and line-height set |
| Class selector used | 10 | At least one `.classname` rule applied to HTML element(s) |
| ID selector used | 5 | At least one `#idname` rule applied to one HTML element |
| Image styled | 5 | Border, border-radius, or sizing applied |
| Link styled | 5 | Colour changed |

| **Total** | **60** | |
